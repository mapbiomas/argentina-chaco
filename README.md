# Argentina - Chaco
Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Chaco** region in Argentina.

We highly recommend reading the [Chaco Algorithm Theoretical Basis Document (ATBD)](https://drive.google.com/file/d/1_sDgMTUK9slbXMxzjB7iZobQ5G2OvOv3/view?usp=drive_link). This document provides fundamental information about the classification methodology and each processing step.
