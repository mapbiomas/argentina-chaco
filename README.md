# Argentina - Chaco

Developed by the team of **MapBiomas Argentina**.

## About

This repository contains scripts for classifying and filtering the **Chaco** region in Argentina.

We highly recommend reading the [Chaco Algorithm Theoretical Basis Document (ATBD)](https://argentina.mapbiomas.org/wp-content/uploads/sites/12/2026/02/ATBD-Chaco-Collection-6.0.pdf). This document provides fundamental information about the classification methodology and each processing step.
